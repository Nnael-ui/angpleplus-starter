# Angleplus United Inc. - Starter Website

A simple React + Vite corporate showcase website for Angleplus United Inc.

## Included

- Home page
- About Us
- Products / Solutions
- Reusable product detail pages
- Services
- Projects / Portfolio
- Contact / Inquiry form
- Responsive navigation
- Responsive desktop/tablet/mobile layout
- Mock product/project data
- Backend-ready inquiry form structure

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Next backend steps

The current inquiry form only validates and displays a local success message. A backend can later:

1. Receive POST `/api/inquiries`
2. Store inquiries in MySQL/PostgreSQL
3. Add an admin dashboard
4. Send email notifications
5. Store products/projects in a database
6. Add an image upload system
7. Add authentication for administrators

## Content that should be replaced

The phone number, email, office address, project information, company history, and product specifications are placeholders and should be replaced with Angleplus United Inc.'s official information.

The Unsplash images are temporary visual placeholders. Replace them with the company's actual plant, equipment, project, and office photographs.
